## Add `https` option to `aws_lb_listener`

- add this to alb.tf

```hcl
resource "aws_lb_listener" "https" {
  load_balancer_arn = aws_lb.main.arn

  port     = 443
  protocol = "HTTPS"

  ssl_policy = "ELBSecurityPolicy-2016-08"

  certificate_arn = aws_acm_certificate.main.arn

  depends_on = [aws_acm_certificate_validation.main]

  default_action {
    type             = "forward"
    target_group_arn = aws_lb_target_group.app.arn
  }
}

resource "aws_acm_certificate" "main" {
  domain_name       = var.domain_name
  validation_method = "DNS"

  subject_alternative_names = [
    "*.${var.domain_name}"
  ]

  lifecycle {
    create_before_destroy = true
  }
}

resource "aws_acm_certificate_validation" "main" {
  certificate_arn = aws_acm_certificate.main.arn

  timeouts {
    create = "5m"
  }
}

output "acm_certificate_validation_records" {
  value = {
    for dvo in aws_acm_certificate.main.domain_validation_options : dvo.domain_name => {
      name   = dvo.resource_record_name
      record = dvo.resource_record_value
      type   = dvo.resource_record_type
    }
  }
  description = "Add these CNAME records to Cloudflare to validate the ACM certificate"
}
```

```bash
terraform fmt
terraform plan
terraform apply
```

Now while Terraform is applying, you have 5 minutes to setup the certificate CNAME record in CloudFlare.

Visit the ACM dashboard in AWS, select your new certificate and copy the values into a new CloudFlare DNS record for your domain.

Example :

```text
type = CNAME
name  = _abcdef01234567890abcdef012345678.subdomain.your-domain.tld.
target = _9876543210fedcba9876543210fedcba.jkddzztszm.acm-validations.aws.
Proxy Status = DNS Only
```

Wait for CNAME propagation. Check using [https://www.whatsmydns.net/#CNAME/](https://www.whatsmydns.net/#CNAME/){target=\_blank}

> [!NOTE]
> If you get a timeout error after you apply the terraform configuration, don't worry. Finish setting up the DNS record in CloudFlare, and run `terraform apply` again. It should validate the certificate much faster.

Replace the `aws_lb_listener` `http` entry:

```hcf
resource "aws_lb_listener" "http" {
  load_balancer_arn = aws_lb.main.arn

  port     = 80
  protocol = "HTTP"

  default_action {
    type = "forward"

    target_group_arn = aws_lb_target_group.app.arn
  }
}
```

with :

```hcf
resource "aws_lb_listener" "http" {
  load_balancer_arn = aws_lb.main.arn

  port     = 80
  protocol = "HTTP"

  default_action {
    type = "redirect"

    redirect {
      port        = "443"
      protocol    = "HTTPS"
      status_code = "HTTP_301"
    }
  }
}
```

```bash
terraform apply
```

Now http://adsplatform.sbcode.net/ should auto redirect to https://adsplatform.sbcode.net/

- encrypts browser → Cloudflare only

- encrypts browser → Cloudflare → ALB

> [!WARNING]
> HTML is not cached by default, but you can enable a cache rule.
>
> Caching HTML means all visitors may see the same version of the page. If your homepage has user-specific content (login state, personalized data), visitors could see content meant for someone else. To avoid this:
> Add conditions to exclude dynamic paths (e.g., exclude /api/_ or /dashboard/_)
> Check for the presence of a session cookie and exclude those requests
> Keep the Edge TTL short (e.g., 5–30 minutes) if content changes occasionally

## Add Security Headers Middleware

Add:

```python
@app.middleware("http")
async def add_security_headers(request, call_next):
    response = await call_next(request)

    response.headers["X-Frame-Options"] = "DENY"
    response.headers["X-Content-Type-Options"] = "nosniff"
    response.headers["Referrer-Policy"] = "strict-origin-when-cross-origin"
    response.headers["Permissions-Policy"] = "geolocation=()"

    response.headers["Strict-Transport-Security"] = (
        "max-age=31536000; includeSubDomains; preload"
    )

    response.headers["Content-Security-Policy"] = (
        "default-src 'self'; "
        "img-src 'self' data:; "
        "style-src 'self' 'unsafe-inline'; "
        "script-src 'self' 'unsafe-inline'"
    )

    return response
```

### Why This Matters

These headers help protect against:

- clickjacking
- MIME attacks
- browser exploits
- information leakage

Very important production hardening.
