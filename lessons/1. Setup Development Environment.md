# Setup Development Environment

## Prerequisites

- Windows 11 <sup>[*]<sup>
- Internet connection
- Admin rights on your PC
- A GitHub Account

## Learning Objectives

- Setup WSL2 + VSCode
- Fork and clone the repository
- Create a Python virtual environment
- Install dependencies
- Successfully start the application locally

## Install WSL (Windows Subsystem for Linux)

1. Open **Terminal as Administrator**:

- Press `Win` → type _terminal_ → right-click _Terminal_ → _Run as administrator_

2. Run this command to install WSL (with Ubuntu by default):

   ```bash
   wsl --install
   ```

3. Reboot your computer (important).

4. Install the Ubuntu distro:

   ```bash
   wsl --install -d Ubuntu
   ```

5. As the install finishes, It will ask for a Unix username/password.

   Note: Password is invisible (no `*`), just type and press Enter.

6. Close Terminal, open a new Terminal and confirm WSL is working:

   ```bash
   wsl --list --verbose
   ```

## Install VS Code

1. Go to: [https://code.visualstudio.com/](https://code.visualstudio.com/)
2. Download and install the **Windows** version.
3. Launch **VS Code** after install.

## Connect VS Code to WSL

### Install the Official `WSL` extension:

1. In VS Code, go to **Extensions** (`Ctrl+Shift+X`)
2. Search for: `WSL`  
   Install the official Microsoft extension (by Microsoft).

### Open project in WSL:

1. Press `Ctrl+Shift+P` → type `WSL: New Window` → press Enter

2. This opens a fresh VS Code window connected to your WSL instance.

## Fork & Clone the Repository

### Fork the repo on GitHub

1. Go to: [https://github.com/Sean-Bradley/Ads-Platform](https://github.com/Sean-Bradley/Ads-Platform){target=\_blank}
2. Click **Fork** (top right) → select your account.

### Clone in WSL

1. In your **WSL terminal** (inside VS Code or standalone), run:

   ```bash
   cd ~
   git clone https://github.com/YOUR-GITHUB-USERNAME/Ads-Platform.git
   ```

   Replace `YOUR-GITHUB-USERNAME` with _your_ GitHub username.

   Your GitHub username is visible in the URL of your forked version of the repository.

2. Verify it cloned:

   ```bash
   ls Ads-Platform
   # You should see files: LICENSE, README.md, requirements.txt, etc.
   ```

## Install Python in WSL (if not present)

Ubuntu/WSL often includes Python, but let’s ensure it’s up-to-date:

```bash
sudo apt update && sudo apt install -y python3 python3-pip python3-venv
```

Verify:

```bash
python3 --version   # e.g., Python 3.14.x
pip3 --version
```

## Create a Virtual Environment

Inside the project folder:

```bash
cd ~/Ads-Platform
python3 -m venv .venv
```

Activate `.venv`:

```bash
source .venv/bin/activate
```

Your prompt should now show: `(.venv) user@machine:~/Ads-Platform$`

## Install Dependencies (`requirements.txt`)

While `.venv` is active:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

Confirm with:

```bash
pip list
# Should show: FastAPI, uvicorn, SQLAlchemy, jinja2, plus many other dependencies.
```

## Start the Project & Visit Webpage

```bash
uvicorn app.main:app --reload
```

> [!NOTE]
> - `uvicorn` is a lightning-fast, asynchronous web server (ASGI) for Python
> - `app.main:app` = run `app` from `app/main.py`
> - `--reload` = auto-reload on code changes (great for dev)

You should see output similar to this:

```
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Started reloader process [12345] using StatReload
INFO:     Started server process [12347]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
```

## Access from Browser:

Open Browser and visit:

`http://localhost:8000`

- You should see the app homepage.

> [!SUCCESS]
> - `/docs` → Swagger UI (auto-generated OpenAPI docs)
> - `/redoc` → ReDoc documentation

## Troubleshooting

### Error `Command 'uvicorn' not found, but can be installed with: sudo apt install uvicorn`

You have probably gone away and come back some other time to run the app again, you open WSL, type `uvicorn app.main:app --reload`, and you get the error `Command 'uvicorn' not found`.

Ensure you have re-activated the python virtual environment, and try again. All the app dependencies were installed into the virtual environment.

```bash
# Ensure you are in the Ads-Platform folder
cd Ads-Platform

# Activate the Python virtual environment
source .venv/bin/activate

# try again
uvicorn app.main:app --reload
```
