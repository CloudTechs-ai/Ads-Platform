## Create Private Subnets

Add:

```hcl
resource "aws_subnet" "private_a" {
  vpc_id = aws_vpc.main.id

  cidr_block = "10.0.11.0/24"

  availability_zone = "<REGION>a"

  tags = {
    Name = "ads-platform-private-a"
  }
}

resource "aws_subnet" "private_b" {
  vpc_id = aws_vpc.main.id

  cidr_block = "10.0.12.0/24"

  availability_zone = "<REGION>b"

  tags = {
    Name = "ads-platform-private-b"
  }
}
```

### Important Note

Private subnets:

- do NOT expose resources directly to the internet

This is where:

- databases
- internal services
- sensitive infrastructure

should live.

## Create RDS Subnet Group

Still inside `rds.tf`:

```hcl
resource "aws_db_subnet_group" "main" {
  name = "ads-platform-db-subnet-group"

  subnet_ids = [
    aws_subnet.private_a.id,
    aws_subnet.private_b.id
  ]

  tags = {
    Name = "ads-platform-db-subnet-group"
  }
}
```

### Why RDS Needs Multiple Subnets

AWS RDS requires:

- multiple availability zones

This enables:

- high availability
- failover
- resilient infrastructure

## Create Database Security Group

Still inside `rds.tf`:

Add:

```hcl
resource "aws_security_group" "rds" {
  name        = "ads-platform-rds"
  description = "Allow PostgreSQL traffic"

  vpc_id = aws_vpc.main.id

  ingress {
    from_port = 5432
    to_port   = 5432
    protocol  = "tcp"

    security_groups = [
      aws_security_group.web.id
    ]
  }

  egress {
    from_port   = 0
    to_port     = 0
    protocol    = "-1"
    cidr_blocks = ["0.0.0.0/0"]
  }

  tags = {
    Name = "ads-platform-rds-sg"
  }
}
```

### Important Security Concept

Notice:

```text
No public internet access to PostgreSQL
```

ONLY:

- ECS tasks

can connect.

## Create PostgreSQL RDS Instance

Add:

```hcl
resource "aws_db_instance" "postgres" {
  identifier = "ads-platform-postgres"

  engine         = "postgres"
  engine_version = "18"

  instance_class = "db.t3.micro"

  allocated_storage = 20

  db_name  = "ads_platform"
  username = "ads_user"
  password = var.db_password

  publicly_accessible = false

  skip_final_snapshot = true

  vpc_security_group_ids = [
    aws_security_group.rds.id
  ]

  db_subnet_group_name = aws_db_subnet_group.main.name
}
```

### Important Cost Warning

We should understand:

- RDS costs money
- always destroy unused infrastructure

## Output the RDS Endpoint

## Update `ecs.tf`

Now update ECS task definition.

Find:

```hcl
environment = [
```

Replace the entire environment block with:

```hcl
environment = [
  {
    name  = "APP_ENV"
    value = "production"
  },
  {
    name  = "APP_HOST"
    value = "0.0.0.0"
  },
  {
    name  = "APP_PORT"
    value = "8000"
  },
  {
    name = "DATABASE_URL"
    value = "postgresql://ads_user:${var.db_password}@${aws_db_instance.postgres.address}:5432/ads_platform"
  }
]
```

### Important Note

Notice:

```text
${var.db_password}
```

A database password is a secret, so we will store it in a file that we won't commit to GitHub.
