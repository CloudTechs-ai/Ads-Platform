## Configure the `awslogs` Log Driver for ECS & CloudWatch

We will then be able to view ECS service container logs and live tail in CloudWatch.

In file:

```text
terraform/aws/ecs.tf
```

Add to the top:

```hcl
resource "aws_cloudwatch_log_group" "ecs" {
  name = "/ecs/ads-platform"
  retention_in_days = 7
}
```

And inside `container_definitions = jsonencode([`

```hcl
      logConfiguration = {
        logDriver = "awslogs"
        options = {
          "awslogs-group"         = aws_cloudwatch_log_group.ecs.name
          "awslogs-region"        = "<REGION>"
          "awslogs-stream-prefix" = "ecs"
        }
      }
```

## Create Grafana IAM User With Terraform

Create:

```text
terraform/aws/grafana-iam.tf
```

Add:

```hcl
resource "aws_iam_user" "grafana" {
  name = "Grafana"

  tags = {
    Name = "grafana-monitoring-user"
  }
}

resource "aws_iam_access_key" "grafana" {
  user = aws_iam_user.grafana.name
}

resource "aws_iam_user_policy_attachment" "grafana_cloudwatch" {
  user       = aws_iam_user.grafana.name
  policy_arn = "arn:aws:iam::aws:policy/CloudWatchReadOnlyAccess"
}

output "grafana_access_key_id" {
  value = aws_iam_access_key.grafana.id
}

output "grafana_secret_access_key" {
  value     = aws_iam_access_key.grafana.secret
  sensitive = true
}
```

## Update ECS Image Reference and Ignore Further Changes to the Task Definition

If we re apply the Terraform configuration, it will reset the ECS image to the version tagged `:latest`.

Update the container definition image value to reference your most recent ECR image.

We can also add an ignore directive for the `aws_ecs_task_definition` so that it never rolls back to a previous image again.

In `service.tf`, after line:

```hcl
  launch_type = "FARGATE"
```

Add:

```hcl
  lifecycle {
    ignore_changes = [
      task_definition
    ]
  }
```

Next we will apply the terraform config, however, we will need to still run the GitHib action later to fully complete this change.
